# AQUERIVA — Custom Branded Packaged Drinking Water

A modern, high-performance, single-page landing page featuring dynamic visual effects (VFX) and a real-time quotation calculator for **Aqueriva**, a customized packaged drinking water business based in Jaipur.

---

## 🌊 Features

* **Interactive VFX Canvas:** Vanilla JavaScript animated floating water bubbles and ambient glow gradients matching the brand aesthetic.
* **Instant Quotation Engine:** 
  * Select bottle sizes (250 ml, 500 ml, 1000 ml).
  * Choose label finishes (Glossy Vinyl, Velvet Matte, Metallic Gold/Silver Foil).
  * Interactive range slider for quantities (300 to 10,000+ units) with automatic volume discounts.
* **Direct WhatsApp Integration:** Generates a pre-formatted message with order specifications and opens WhatsApp directly to request sampling and design mockups.
* **Responsive Glassmorphism UI:** Built with modern CSS backdrop-filters, responsive layouts, and full mobile optimization.
* **Zero Dependencies:** Pure HTML5, CSS3, and Vanilla JavaScript. No framework setup or build steps required.
